# Acadamus - Project Report

## Introduction
Acadamus is a comprehensive educational management and timetable tracking application designed to streamline communication and scheduling within an academic institution. The platform bridges the gap between administrators, teachers, and students by providing a centralized hub for all academic activities.

## Purpose of the Application
The primary purpose of Acadamus is to eliminate the chaos of manual scheduling and disjointed communication. It was created to:
1. **Centralize Information:** Bring timetables, exam schedules, and administrative announcements into one accessible platform.
2. **Enhance Communication:** Provide a direct, real-time messaging channel between users (students/teachers) and the administration.
3. **Automate Assistance:** Utilize an AI-powered assistant to help users quickly find their schedules without needing manual intervention.
4. **Improve Accessibility:** Ensure that crucial academic information is available across all devices, complete with dark/light mode support and offline capabilities via PWA (Progressive Web App) integration.

## Key Features

### 🤖 AI Assistant
A smart, interactive chatbot that understands natural language. Users can ask questions like "When is my next Math class?" or "Show me my schedule for Monday," and the AI instantly fetches and presents the relevant data.

### 📅 Schedule Management (Classes)
- View daily and weekly timetables.
- Export schedules directly to PDF for offline viewing or printing.
- Administrators can easily add, edit, or remove classes and assign instructors.

### 📄 Examination Tracking (Papers)
- Dedicated module for tracking upcoming exams, quizzes, and assignments.
- Differentiated views for students (standard schedule) and teachers (includes invigilation duties).
- PDF export tailored for different roles.

### 💬 Real-time Communication (Messages)
- A secure, direct line of communication between users and the admin.
- Real-time updates with unread message badges.
- Automated system broadcasts (e.g., Changelogs and App Updates) to keep all users informed.

### 📊 Dashboard & Analytics
- A quick overview of all active modules.
- Admin dashboard includes email logs and system health monitoring.

### ⚙️ Advanced Technical Features
- **Progressive Web App (PWA):** Can be installed on mobile and desktop for a native app-like experience.
- **Firebase Integration:** Secure authentication and real-time NoSQL database (Firestore).
- **Responsive UI:** Modern, "Liquid Glass" aesthetic built with Tailwind CSS and Framer Motion for smooth animations.
- **Role-based Access Control:** Distinct interfaces and permissions for Administrators and standard Users.
